Day-to-day ship path
  1. Confirm the order in Shopify Orders (Unfulfilled).
  2. Open the same order in Shippo and set weight and dimensions.
  3. Pick a carrier rate, buy the label, print.
  4. Shippo syncs tracking and marks it fulfilled; the customer gets Shopify’s shipping email if that sync option is on.

Refunds and cancellations stay on the Shopify order page. The rates customers pay at checkout are under Settings → Shipping and delivery (currently flat Standard $8 / $0 and Express $15), separate from what you pay Shippo for the label.

One-time Shippo setup
  1. Complete the Locations street address.
  2. Install Shippo on chrgrk-ff and authorize.
  3. In Shippo Stores → Manage, turn on tracking sync and Shopify customer notification.
  4. Smoke-test one order end to end (label → fulfilled in Shopify).

Shopify day to day

Discount codes

Create and edit codes under Discounts (percentage, fixed amount, free shipping, automatic). This app has no discount UI; the storefront honors whatever Shopify applies at checkout.

Products and inventory

Manage the catalog in Products. The site reads the Storefront API; after catalog changes, soft-refresh the live site. Bulk port scripts live under npm run catalog:* for developers.

Purchase analytics pixel

Checkout purchase events fire from a Shopify Customer Events custom pixel named Sunday Rolls GA4. Confirm it under Settings → Customer events. Setup notes: SHOPIFY_WEB_PIXEL.md

Print review QR codes

QR codes open a product page with the leave-a-review form (?review=1). The dashboard PDF export is the preferred path.

  1. Open the analytics dashboard → Data.
  2. Under Review QR codes, pick GitHub Pages or Live site.
  3. Click Export PDF: one letter page per product, 3×3 cutouts.

CLI fallback from the repo root: npm run reviews:qr:pages or npm run reviews:qr:live → output/product-review-qrs/. Details: REVIEW_QR_CODES.md

Contact and reviews

Contact form submissions go to Resend → CONTACT_TO_EMAIL and are stored in Postgres. Product reviews also land in Postgres (and email). Use Dashboard → Tests to smoke-test contact, reviews and a tagged $0 order. See CONTACT_EMAIL.md.

    First-time setup

    You need two env files and two processes. Secrets come from Railway, Shopify Admin or the team. Never invent or commit them; start from the examples.

    Commands

    SPA: cp .env.example .env && npm install && npm run dev

    API: cd server && cp .env.example .env && npm install && npm run dev

    Dashboard locally: http://localhost:3001/dashboard/
